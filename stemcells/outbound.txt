# Every host the shipped code names, and every file that may name an install,
# anonymous or analytics id, an update feed or a crash reporter, each with why
# it may stay. `apps/server/src/stemcells/privacy/noTelemetry.test.ts` fails on
# one this list lacks, and on a line here the code no longer needs, so a sync
# that brings a new one stops until someone reads what it does
# (`stemcells/docs/upstream-sync.md`, Outbound). No analytics, crash-reporting
# or tracing package is allowed at all.
#
#   host <name> <why>
#   id <file> <why>
#   forbid <address prefix> <why>   no shipped code fetches from it
#   cut <file> <why>                a file that still names a forbidden
#                                   address, and why it's never fetched
#   live <host>[/<path>] <why>      a host, or the URLs under a path, the
#                                   running app may contact
#
# Loopback, an IP address and the reserved example names need no line.
#
# `live` is the runtime half: a host the running app contacts with no one
# asking, which `stemcells/lab/outbound-live.mjs` (the outbound-live gate)
# lets pass. Its why names what removes it; the gate fails on a `live` host
# it no longer sees, so these only go.
